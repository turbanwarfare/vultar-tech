# Vultar

Open source clan tech from Vultar. All credit goes to the original tech developers.

Contains the game, admin, anti-cheat, a Discord bot and an API. Game assets aren't included.

Secrets and personal info have been removed, so webhooks, API keys and some IDs need to be filled in before it works. Searching for `REPLACE_WITH_YOUR_` finds most of them.

## Building

```bash
rokit install
wally install
rojo build build.project.json -o MainModule.rbxm
```
